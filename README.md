# Agente Preditivo Netflix

Projeto prático de Inteligência Artificial que utiliza o dataset Netflix Movies and TV Shows, do Kaggle, para treinar modelos preditivos capazes de classificar títulos como Movie ou TV Show.

Além da predição, o projeto integra um agente inteligente via Gemini API para explicar o resultado do modelo em linguagem natural.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-Learn
- Joblib
- FastAPI
- Streamlit
- Gemini API
